### Что покрыто тестами
- Приёмочный пример ТЗ §11: HFOV 87,917° (в ТЗ «≈ 87,9»), ширина 19,2857142857 м, высота 10,8571428571 м, 132,74074074 px/m — относительная погрешность < 1e-9. Профиль 2014: 25 / 62,5 / 125 — есть, 250 — нет. Профиль 2025: 20 / 40 / 80 / 125 — есть, 250 / 500 / 1500 — нет.
- Свойства модели: угол растёт с матрицей и падает с фокусом; ширина линейна по D; плотность обратно пропорциональна D; длиннее фокус — выше плотность и уже охват; горизонталь и вертикаль согласованы при квадратном пикселе; паспортный угол ≡ угол из матрицы.
- Обратный расчёт: требуемые угол и фокус дают ровно заданную ширину (< 1e-12); фокус под плотность даёт ровно порог; `ceil(W·PPM)` без лишнего пикселя от погрешности double (0,1·3·1000 = 300); обе проверки подбора («узкий объектив» и «широкий объектив»).
- Вариофокал: на краях диапазона — паспортные углы; угол монотонно сужается; фокус вне диапазона и перевёрнутые углы — отказ.
- Высота и наклон: кромки кадра; верхняя кромка выше горизонта → ∞; глубина ↔ дальность по земле взаимно обратны; при наведении глубина = наклонная дальность; участок уровня внутри видимого участка; камера не выше цели — отказ.
- Пороги: ниже / ровно на / выше каждого уровня обеих редакций; пороги строго растут; id профилей различаются; уровень другой редакции в задаче отклоняется.
- Недопустимый ввод: NaN, ±Infinity, 0, отрицательные, undefined, null, строка, дробные пиксели, угол 180°.
- Ссылка: туда-обратно без потерь (4 сценария), версия движка и профиль в ссылке, мусор (`1e3`, `-5`, `1440.5`, `NaN`, 40 девяток, `<script>`, `Infinity`, неизвестный профиль) → значения по умолчанию.

- UZ на 375 px: горизонтальной прокрутки страницы нет (scrollWidth = clientWidth = 375), широкая таблица уровней прокручивается внутри своего блока.

**Ограничение проверки.** В той же папке работает dev-сервер другой сессии. Оба сервера пишут в общий `apps/web/.next`, поэтому браузер получал то новую, то старую клиентскую сборку: в консоли была ошибка гидратации, где сервер отдавал новую разметку, а клиент — старую. К коду страницы это не относится: значения из ссылки читаются только в `useEffect`, на сервере и в браузере рендер одинаковый, числа форматируются своей функцией без Intl. Окончательная проверка — production-сборка в изолированной копии (§3).
