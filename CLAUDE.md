# satsolutions.uz — ориентировка для новой сессии

Сайт и каталог SAT Solutions (Ташкент): слаботочные системы — видеонаблюдение, СКУД, турникеты, пожарная сигнализация, домофония, сети, серверные. Монорепо: `apps/web` (Next.js), `apps/api` (Express + Sequelize + PostgreSQL), `apps/admin`. Прод — свой сервер под PM2, алиас `satweb-prod`.

**Масштаб:** 3256 опубликованных товаров, 212 категорий, 34 бренда, 63 статьи блога, 115 категорийных лонгридов — всё на пяти языках.

## ⛔ Правила, которые нельзя нарушать

1. **Сайт на пяти языках: ru / uz / en / tr / zh.** Любой новый контент выходит сразу на всех пяти. Не «tr и zh потом».
2. **Прод, реклама, деньги — только с явного «да» на конкретное действие.** Вопрос владельца («а можно?») согласием не является.
3. **Платные API** (Anthropic, fal и др.) — только с разрешения на конкретный запуск и с озвученной стоимостью.
4. **Изменение товара** — обязательно обновить переводы в `productI18n.json` и `seoTitle`/`seoDescription`.
5. **Любое изменение сайта** — с учётом SEO: slug и редиректы, canonical, hreflang, sitemap.
6. **Узбекский в текстах объявлений Google Ads запрещён** (тексты, пути, посадочные). Английский, турецкий, китайский — можно. Узбекскими бывают только ключи.
7. **Скрипты-правки** — с сухим прогоном по умолчанию, запись только по флагу `--apply`.

## Деплой

```bash
npm run deploy
```
Строго из корня репозитория и **только после `git push`** — иначе сервер выкатит предыдущий коммит и отрапортует об успехе. Проверка: `ssh satweb-prod 'cd /var/www/satweb && git log --oneline -1'` должен показать ваш коммит.
