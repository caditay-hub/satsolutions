# SEO-проверка satsolutions.uz

Сайт на 5 локалях (ru/uz/en/tr/zh), все переведены полностью. Полный промпт-чек-лист — `prompt-seo-check.md` в корне репо.

## 1. ⚠️ КАК ЧИТАТЬ ЦИФРЫ GSC (главное — не попасться)

**Мусорный ботовый поток.** Запросы вида `ai12345` (regex `^ai\d{4,6}$`) — тысячи показов, НОЛЬ кликов. За неделю 07.09.2026: 1022 → 3119 показов, 1731 уникальный запрос, **72% всего прироста показов**. Механически роняют CTR и порождают ложную тревогу «показы растут, клики падают».
⚠️ Сидят и ВНУТРИ узбекского сегмента (3098 из 6539) — фильтра по стране мало.

**Зарубежные показы по кодам моделей.** Английские карточки `/en/products/...` ранжируются в ОАЭ, Египте, Бангладеш по артикулам («ds-3e1510p-si-8p2f»), позиции 4–8, кликов ноль. Это не наш рынок и не дефект сниппета — заголовки там правильные (артикул + цена + наличие). США: 1169 показов / 4 клика. Узбекистан: 34 061 / 1360 / CTR 3,99%.

**Недельная средняя позиция ВРЁТ.** Брендовый «sat solutions» показывал позицию 13,3 — по дням это 1,0 почти каждый день плюс два аномальных дня (40 и 17). **Любую просадку позиции проверять по ДНЯМ (`dimensions: ['date']`), а не по среднему.**

**Правильный расчёт чистых цифр:** срез по запросам НЕ отдаёт анонимизированные запросы (их около половины), поэтому чистый итог = полный итог по стране МИНУС измеренный мусор. Суммировать «живые» строки нельзя — потеряется половина.

**Мониторинг уже это учитывает** (коммиты b57bdbb, e2f103a): `apps/api/src/monitor/sources/searchConsole.ts` тянет сегмент `country=uzb`, вычитает мусор (`JUNK_QUERY`, `subtractJunk`), отдаёт `home` и `homeJunk`; тревоги и дайджест в `analyze.ts` считаются по чистому домашнему сегменту; `render.ts` показывает вторую таблицу «🇺🇿 Узбекистан» с пометкой, сколько отсеяно. `prev` имеет форму `{all, home}` (чтение старых снапшотов сохранено).

## 2. Скорость посадочных — частая причина низкого качества
Google Ads оценивает посадочную и по СКОРОСТИ. Прецедент 08.09.2026: у `/solutions/videowall` герой-картинка весила 223 КБ (соседняя при похожем размере — 53 КБ), LCP 4,8 с, оценка «ниже среднего». После пережатия 74 КБ → **балл 81→98, LCP 2,3 с**.
Оказалось системным: **66 JPEG тяжелее 120 КБ** в `/var/www/satweb/apps/api/uploads/services-page/` (до 400 КБ). Пакетное пережатие (ширина ≤1200, quality 76, progressive) дало **11,8 → 5,9 МБ**. Бэкап `/root/svcimg_bak_20260908`.
- Проверка: `npx tsx /root/psi3.mts` из `/var/www/satweb/apps/api` (ключ — `config.psiApiKey`, НЕ `psiKey`).
- Тяжёлые ресурсы страницы: аудит `network-requests` в ответе PSI.
- ⚠️ После правки файлов картинок обязателен `chown www-data:www-data *.jpg` — Python пишет от root.
- ⚠️ Разброс баллов PSI между прогонами ±5 — не гнаться за шумом, смотреть на LCP.

## 3. Индексация
- `apps/api/src/monitor/indexCheck.ts` — прогон 258+ SEO-URL; в боте sat-monitor-bot команда `/index`, cron пн 09:00.
- Web Search Indexing API: `/root/gindex.cjs`, очередь `/root/gindex_queue.json`, cron `gindex_daily` 08:20 UTC, 150 URL/день. Использовать после любых новых страниц.
- IndexNow дифф-отправка встроена в деплой (`indexNow.ts`).

## 4. Техническая база (curl всегда с `-A "Mozilla/5.0..."` — иначе 403 от антискрейпа)
- Sitemap обязан содержать ВСЕ 5 локалей отдельными `<loc>`, а не только в hreflang-альтернатах.
- Снятые товары → 308 на `/catalog/<brand>` (`removedProducts.ts` + middleware). Новые 404 из GSC — туда же.
- Фильтровые URL — noindex; редиректы старого сайта (`/product/show`, `/category`, `/brand`) работают.
- Категорийные страницы НЕ должны отдавать Product-разметку (проверено — не отдают); товары без цены не выводят `offers` и не попадают в товарный фид.

## 5. Контент
- **Аудит:** `cd apps/web && npx tsx scripts/content_audit.ts` — метрики всех статей, услуг, тип-лендингов, брендов по 5 локалям, помечает «МАЛО» и штампы.
- Пороги: статья ≥350 слов RU, услуга ≥400.
- Тексты услуг — `apps/web/src/lib/serviceContent.ts`. ⚠️ В константах `ru`/`uz` ключи БЕЗ кавычек (`  cctv: {`), в `en`/`tr`/`zh` — В КАВЫЧКАХ (`  "cctv": {`). Регулярка: `^  "?<key>"?: \{`.
- Статьи — `apps/web/src/lib/articlesData.ts`. Два формата секций: однострочный `{ h: "…", p: [` и многострочный `sections: [{\n  h: "…"`. Регулярка `\{\s*h:\s*`. После вставки чинить пропущенную запятую: `\}(\s*)\{ h: ` → `},\1{ h: `.
- Новая секция ставится ПЕРЕД «Выводом» только если он есть (regex `вывод|итог|заключен`) — у большинства статей последняя секция содержательная, слепой свап всё портит.

## 6. ⚠️ КАК ПРОВЕРЯТЬ ТЕКСТ НА СТРАНИЦЕ
`curl | sed 's/<[^>]*>/ /g' | grep -i «фраза»` даёт **ЛОЖНЫЕ НУЛИ** на многословных фразах. Проверять питоном: снять script/style, снять теги, схлопнуть пробелы, искать подстроку в собранном тексте. Образцы: `scratchpad/check_lp.py`, `scratchpad/lp_words.py`.
